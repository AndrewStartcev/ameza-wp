# AMEZA — WordPress

Кастомная классическая тема AMEZA из предоставленного HTML-макета.

Стек: WordPress 6.5+, PHP 8.1+, ACF PRO, Contact Form 7, Rank Math SEO Free. Код разделён на PHP, CSS и JS.

## Что происходит после обновления темы на сервере

Войди в /wp-admin/ с правами администратора. Если страницы ещё не существуют, тема создаёт:

- Главная — обычная опубликованная страница WordPress с полями ACF (без лишнего классического редактора).
- Политика конфиденциальности — черновик с шаблонным текстом.
- Публичная оферта — черновик с шаблонным текстом.
- Согласие на обработку ПД — черновик с шаблонным текстом.

Миграция inc/seed.php однократно заполняет пустые поля главной содержимым исходного HTML: все секции, тексты, карточки, отзывы, FAQ, кнопки, контактные данные, оценки 5/5. Ранее заполненные поля не переписываются. Восстановление иконок, рейтингов и медиа выполняется однократно — после ручного удаления они не должны появляться снова.

Изображения и значки из assets/uploads-ready импортируются в медиатеку (inc/media.php). Фотографии автоматически прикрепляются к пустым ACF-полям; исходные иконки Font Awesome Free назначаются полям «Иконка» у карточек/преимуществ. В ACF нет селектов выбора иконок: **одно поле типа Image**, а вкладки всегда вертикальные слева.

Если меню ещё не назначено, создаются основное и нижнее меню с якорями из HTML. Когда активен Contact Form 7, inc/forms.php создаёт две реальные формы и связывает с настройками сайта, если там ещё нет шорткодов.

## Как редактировать

- Страницы → Главная: все секции, фото, текст, иконки и рейтинг отзывов.
- Настройки сайта: контакты, логотип, реквизиты, ссылки, формы.
- Страницы → Политика / Оферта / Согласие: обычный редактор WordPress.

## Важно перед публикацией

Контактные данные, отзывы, количество клиентов, сроки изготовления, сертификаты и иные заявления перенесены из исходного HTML без внешней проверки — это демонстрационный контент. Проверь их перед запуском.

Юридические страницы **остаются черновиками** до заполнения квадратных заглушек и правовой проверки. У сайта пока не подтверждены реквизиты и порядок акцепта оферты; публикация шаблона без изменений не рекомендуется.

Две фотографии соответствуют исходным работающим ссылкам. Товарная картинка исходного HTML отдаёт 404, поэтому использована отдельно обозначенная замена с Pexels. Все четыре карточки в исходном HTML указывали на одну фотографию.

## Файлы

- front-page.php — главная.
- inc/acf.php — ACF-поля.
- inc/seed.php — однократное наполнение из HTML.
- inc/legal-content.php — шаблоны юридических страниц.
- inc/pages.php — создание страниц.
- inc/media.php — импорт в медиатеку.
- inc/forms.php — формы CF7.
- assets/css/ameza.css, assets/css/admin.css — стили сайта и редактора.
- assets/js/ameza.js — скрипты.

**GitHub commit сам по себе не меняет БД WordPress.** Автозаполнение выполнится только после выкладки обновлённой темы на сервер и следующего входа администратора. GitHub Actions проверяет синтаксис PHP, но не заменяет визуальное и функциональное тестирование WordPress.

## Принудительное повторное наполнение из оригинального HTML (v4)

По явному запросу владельца теперь применяется миграция v4: **один раз перезаписывает все ACF-поля главной**, даже если данные уже существуют; использует изображения из медиатеки, импортированные в inc/media.php (hero/production/product/icons), восстанавливает заголовки карточек, FAQ и рейтинги 5/5. Перезаписываются только известные поля AMEZA и демонстрационные контактные настройки, но **не** реальные реквизиты, юридические документы, уже созданные страницы или текущие CF7-шорткоды. Снимок заменённых значений остаётся в опции WordPress ameza_html_rebuild_backup_v4.

Наиболее частые изменения в HTML: номер WhatsApp +7 (495) 123-45-67, Telegram @ameza_brand. После миграции поля можно редактировать в ACF и они больше не восстанавливаются автоматически.

Формы AMEZA получают 4-строчный комментарий, CSS ограничивает высоту textarea на любых CF7-формах.

Оригинальный HTML содержит только рабочий Telegram URL; ссылки Instagram, Wildberries и Ozon в прототипе равны #. Не подставляем фальшивые ссылки; эти адреса следует заполнить через настройки сайта. Юридические страницы остаются черновиками до проверки, поэтому публичные ссылки на них неактивны.

**Применение:** выкати новый код темы из main, открой /wp-admin/ администратором; миграция запустится однократно. Без подключения к базе сайта GitHub не может сам изменить содержимое WordPress.
