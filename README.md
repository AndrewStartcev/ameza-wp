# AMEZA — WordPress

Кастомная классическая WordPress-тема на основе HTML-прототипа \`deepseek_html_20261110_3db2cb.html\`.

**Стек:** WordPress 6.5+, PHP 8.1+, ACF PRO, Contact Form 7, Rank Math SEO Free.

## Структура

- \`front-page.php\` — лендинг: Hero, преимущества, продукция, производство, опт, отзывы, FAQ, контакты
- \`header.php\`, \`footer.php\` — навигация, контакты, документы, соцсети
- \`page.php\` — юридические и обычные текстовые страницы
- \`assets/css/ameza.css\` — стили исходного HTML, адаптив, дополнения
- \`assets/js/ameza.js\` — мобильное меню; FAQ работает через нативные details/summary
- \`assets/icons/*.svg\` — 18 отдельных SVG-иконок, вместо Font Awesome
- \`assets/img/*.svg\` — 7 отдельных локальных иллюстраций-заглушек вместо внешних картинок; поле ACF позволяет загрузить реальную фотографию
- \`inc/acf.php\` — поля лендинга, настройки компании, JSON Sync
- \`inc/defaults.php\` — демонстрационные тексты из HTML-прототипа, fallback до заполнения ACF
- \`inc/cleanup.php\` — безопасное отключение неиспользуемого WP; REST API, SEO, CF7 сохранены
- \`docs/contact-form-7.md\` — образцы двух форм

## Установка

1. Установи WordPress. Размести содержимое репозитория в \`wp-content/themes/ameza-wp/\`.
2. Активируй тему AMEZA в разделе «Внешний вид».
3. Установи **ACF PRO**, **Contact Form 7** и **Rank Math SEO Free** отдельно. Плагины и ключ ACF не входят в Git.
4. Создай страницу «Главная», выбери её в **Настройки → Чтение → Статическая главная**. АCF-поля главной станут доступны для редактирования.
5. В **Настройки сайта** измени логотип/контакты/реквизиты и укажи шорткоды CF7.
6. Создай страницы «Политика конфиденциальности», «Согласие на обработку ПД», при необходимости «Публичная оферта». Укажи первую в **Настройки → Конфиденциальность**, остальные привяжи в настройках сайта.
7. В **Внешний вид → Меню** можно назначить собственную навигацию, либо останется корректное меню с якорями лендинга.
8. Настрой Rank Math: XML sitemap, индексируемость, Title, Description, OG и базовую schema; не используй параллельный SEO-плагин.

## ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ

HTML-прототип содержит **неподтверждённые демонстрационные сведения**: телефон +7 (495) 123-45-67, адрес, Email, Telegram, рекордные объёмы, сертификаты, условия производства и доставки, а также отзывы с именами компаний. Они сохранены как fallback для проверки вёрстки, **не подтверждены как факты об AMEZA и должны быть заменены/согласованы** перед публикацией.

Стоковые изображения Unsplash в исходном HTML были внешними URL без исходных медиафайлов. Чтобы тема работала полностью локально, добавлены авторские **SVG-иллюстрации-заглушки**. Их не следует выдавать за фото продукции/производства. Для реального запуска загрузи фотографии через поля ACF: hero, product cards и about.

SVG иконки находятся **отдельными файлами** в теме и загружаются с сервера темы, не через внешние CSS/CDN. WordPress по умолчанию не разрешает загрузку SVG в медиабиблиотеку; для замены изображений через ACF рекомендуется WebP/JPEG/PNG. Не включай небезопасный SVG-upload без санитайзера.

Шрифты **Inter** и **Playfair Display** пока подключаются через Google Fonts, как в исходном HTML. Перед продакшеном при необходимости перенеси их в локальные WOFF2 с соблюдением лицензий.

### Формы

Настрой в CF7 две формы по [инструкции](docs/contact-form-7.md). Пока шорткоды не заполнены, тема показывает телефон вместо фиктивного сообщения «заявка отправлена». Письма/передача данных не работают до настройки реального CF7/почты.

### SEO

Тема **не выводит SEO Title/Description/Canonical/JSON-LD самостоятельно**, чтобы исключить конфликты с Rank Math. Правильные значения задаются в Rank Math. WordPress \`wp_head\` и \`wp_footer\` не отключены.

### Разработка

Готовая вёрстка сохранена по структуре и визуальной стилистике исходника. В CSS/JS нет Font Awesome. Для цветов и секций используются существующие классы прототипа; новые служебные компоненты используют отдельные именованные CSS-классы.
